# NormDef-FR

NormDef-FR is a manually validated dataset for extracting and validating normative definitions in French legal codes.

The first public release contains 693 gold definitions from 363 source articles, with article-level and candidate-validation benchmarks.

It includes gold annotations, metadata, train/dev/test splits, verified true negatives, baseline scripts, and experimental results.

Main documentation:
- `DATA_CARD.md`
- `MODEL_CARD.md`
- `ANNOTATION_GUIDELINES.md`
- `ANNOTATION_GUIDELINES_FR.md`

Experiments can be reproduced from `scripts/experiments/`.
